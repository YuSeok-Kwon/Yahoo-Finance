# Tableau 대시보드 시트별 설명

## 1. 투자 가이드

투자자 성향과 전략 기간에 맞는 추천 산업을 단계별로 탐색하기 위한 대시보드입니다.

* 투자 성향(공격형/균형형/안정형) 파라미터와 전략 기간(단타/스윙/장기투자) 필터로 조건별 추천 결과를 동적으로 전환합니다.
* STEP 1에서는 섹터별 시장 규모 트리맵과 추천 산업 KPI(산업 수·수익률·Sharpe Ratio·MDD)로 거시적 구조를 파악합니다.
* STEP 2에서는 섹터 수익률 랭킹 막대 차트로 시장 규모 대비 실제 수익률 괴리를 식별하고, 섹터 클릭 시 하단이 연동 필터링됩니다.
* STEP 3에서는 변동성-수익률 산점도에 KMeans(k=5) 클러스터를 색상으로, 추천 산업을 크기·라벨로 하이라이트하여 리스크-수익 포지션을 시각화합니다.
* STEP 4에서는 MDD·변동성·수익률·Sharpe Ratio 4개 지표를 인라인 막대로 비교하는 산업 리스트를 추천 우선 정렬로 제공합니다.

## 2. 모델 검증

Prophet+XGBoost 하이브리드 모델의 예측 성능을 공개하여 추천 결과의 신뢰도를 검증하기 위한 대시보드입니다.

* 상단 KPI에서 지수 예측 정확률(93.24%), 예측/순위 정확도(74.6%/73.8%), 총 분석 데이터(844,822+)를 요약합니다.
* 중단에서는 섹터별 실제 vs 예측 지수 비교와 예측 오차율 차트로 모델의 섹터별 강점/약점을 식별합니다.
* 하단에서는 NDCG@5 개선 비교(0.24→1.23), SHAP Top 7 특징 중요도(상위 3개가 기여도 60.4%), GridSearch 36조합 히트맵(최적 α=0.7, γ=0.25)으로 모델 작동 원리와 파라미터 선택 근거를 제시합니다.
