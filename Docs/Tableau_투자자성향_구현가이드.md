# Tableau 투자자 성향 추천 — 통합 대시보드 구현 가이드

> **핵심 전략:** 별도 데이터 원본을 추가하지 않고, 기존 industry_features에 추천 컬럼을 병합한
> **단일 통합 CSV**를 사용. 기존 산점도·섹터 랭킹을 그대로 유지하면서 성향 추천이 자연스럽게 녹아듦.

---

## 데이터 구조

파이프라인 실행 시 `Data_set/Cluster_Results/`에 생성되는 파일:

```
{date}_unified_industry_features.csv   ← Tableau에서 사용할 파일
```

| 컬럼 | 설명 | 예시값 |
|------|------|--------|

| Industry | 산업명 | Software, Oil & Gas |

| Num_Companies | 소속 기업 수 | 50 |

**추가된 컬럼 (성향별 추천 정보)**

| 컬럼 | 설명 | 예시값 |
|------|------|--------|
| Cluster_Name | 클러스터 한글명 | 강력매수, 고수익·고위험 |

| Is_추천_안정형 | 안정형 추천 여부 | True / False |
| Rank_안정형 | 안정형 추천 순위 | 1~5 (비추천=0) |
| Score_안정형 | 안정형 composite score | 0.56 |

모든 산업이 포함되며, 추천되지 않은 산업은 `Is_추천_*=False`, `Rank_*=0`.

## PHASE 1: 데이터 원본 교체 (3분)

기존 `stock_features_full+` (여러 CSV 유니온)를 **통합 CSV 하나**로 교체.

1. Tableau Desktop → 데이터 원본 탭
2. 기존 `stock_features_full+` 데이터 원본을 우클릭 → "편집"
3. 기존 유니온 연결을 제거하고, `{date}_unified_industry_features.csv` 단일 파일로 교체
4. (또는) 새 데이터 원본으로 추가 후 기존 워크시트의 데이터 원본을 일괄 교체:
   - 기존 데이터 원본 우클릭 → "데이터 원본 바꾸기" → 새 데이터 원본 선택

> **장점:** 블렌딩 없이 단일 데이터 원본으로 운영. CORR 함수 오류 발생 불가.

## PHASE 2: 매개변수 생성 (2분)

### P_투자자성향
- 데이터 패널 상단 드롭다운 → "매개변수 만들기"
- 이름: `P_투자자성향`
- 데이터 유형: 문자열
- 허용 가능한 값: 목록
- 값 목록: `공격형`, `균형형`, `안정형`
- 현재 값: `균형형`

---

## PHASE 3: 계산된 필드 (5분)

### 필드 1: C_추천여부 (핵심)

매개변수에 따라 해당 성향의 추천 여부를 반환:

```
CASE [P_투자자성향]
  WHEN "공격형" THEN [Is_추천_공격형]
  WHEN "균형형" THEN [Is_추천_균형형]
  WHEN "안정형" THEN [Is_추천_안정형]
END
```

### 필드 2: C_추천순위

```
CASE [P_투자자성향]
  WHEN "공격형" THEN [Rank_공격형]
  WHEN "균형형" THEN [Rank_균형형]
  WHEN "안정형" THEN [Rank_안정형]
END
```

### 필드 3: C_추천점수

```
CASE [P_투자자성향]
  WHEN "공격형" THEN [Score_공격형]
  WHEN "균형형" THEN [Score_균형형]
  WHEN "안정형" THEN [Score_안정형]
END
```

### 필드 4: C_성향설명

```
CASE [P_투자자성향]
  WHEN "공격형" THEN "높은 수익을 위해 높은 리스크를 감수하는 투자자"
  WHEN "균형형" THEN "적절한 리스크로 안정적 수익을 추구하는 투자자"
  WHEN "안정형" THEN "원금 보존을 최우선으로 하는 보수적 투자자"
END
```

### 필드 5: C_추천라벨 (산점도용)

추천 산업에만 이름을 표시하고 비추천은 빈 문자열:

```
IF [C_추천여부] = TRUE
  THEN STR([C_추천순위]) + ". " + [Industry]
  ELSE ""
END
```

### 필드 6: C_마크크기 (산점도용)

추천 산업은 크게, 비추천은 작게:

```
IF [C_추천여부] = TRUE THEN 3 ELSE 1 END
```

### 필드 7: C_마크색상구분

추천 산업은 클러스터 색상, 비추천은 회색으로:

```
IF [C_추천여부] = TRUE
  THEN [Cluster_Name]
  ELSE "비추천"
END
```

## PHASE 4: 기존 워크시트 수정 (10분)

> 새 워크시트를 만들지 않고, 기존 워크시트에 추천 기능을 추가.

### 4-1. 산점도 수정

기존 산점도 워크시트를 열고:

1. **색상**: 기존 `cluster` → `C_마크색상구분` 으로 교체
   - 색상 편집에서 "비추천"을 `#D0D0D0` (연한 회색)으로 설정
   - 나머지 클러스터 색상은 기존과 동일하게 유지
2. **크기**: `C_마크크기`를 크기 선반에 추가
   - 추천 산업이 시각적으로 강조됨
3. **레이블**: 기존 Industry 레이블을 `C_추천라벨`로 교체
   - 추천 산업에만 순위+이름 표시, 비추천은 레이블 없음
4. **도구설명**: 기존 도구설명에 추가:
```
추천 순위: <C_추천순위>위
추천 점수: <AVG(C_추천점수)>
```

### 4-2. 섹터 랭킹 수정

기존 섹터 랭킹 워크시트를 열고:

1. **색상**: 기존 색상 → `C_마크색상구분`으로 교체
   - "비추천" = 연한 회색, 추천 산업만 클러스터 색상으로 표시
2. **레이블**: 기존 레이블에 `C_추천순위` 추가
   - 추천 산업 옆에 "1위", "2위" 등 순위 표시
3. **정렬**: `C_추천순위` 오름차순으로 변경 (추천 산업이 위로)
   - 또는 기존 Return_Period/Sharpe 정렬 유지하되, 추천 산업이 색상으로 구분됨

### 4-3. 산업 리스트 수정

기존 산업 리스트 테이블에 컬럼 추가:

1. `C_추천여부` 컬럼 추가 (True/False)
2. `C_추천순위` 컬럼 추가
3. (선택) 행 색상을 `C_마크색상구분`으로 적용

## PHASE 5: 성향 선택 버튼 워크시트 (5분)

### 방법 A: 간단한 텍스트 버튼

1. 새 워크시트 → 이름: `성향 선택 버튼`
2. 계산된 필드 `C_성향목록` 생성:
```
"공격형"
```
→ 이 방법 대신, 더 간단하게:

3. 열: 없음
4. 마크: 텍스트
5. 텍스트에 `P_투자자성향` 매개변수 표시
6. → 사실 이것보다 **매개변수 컨트롤을 직접 대시보드에 표시**하는 게 더 간단

### 방법 B (권장): 매개변수 컨트롤 표시

대시보드에서:
1. `P_투자자성향` 매개변수를 우클릭 → "매개변수 컨트롤 표시"
2. 컨트롤이 대시보드에 드롭다운/라디오 버튼으로 표시됨
3. 매개변수 컨트롤 > 서식 > "단일 값(라디오)" 선택
4. 상단 기간 선택 버튼 옆에 배치

### 방법 C: 기존과 동일한 버튼 스타일

기간 선택 버튼과 시각적으로 동일한 클릭 버튼을 원하면:

1. 새 워크시트 → 이름: `성향 선택 버튼`
2. 데이터 원본에서 고유한 성향 값을 가져오기 위한 계산 필드:
```
// C_성향버튼값
IF [Is_추천_공격형] = TRUE OR [Is_추천_공격형] = FALSE
  THEN "공격형"
END
```
→ 이보다 더 간단한 방법: 별도의 소규모 CSV 또는 데이터 원본 없이 구현하기 어려움

**실용적 권장:** 방법 B(매개변수 컨트롤 라디오 버튼) 사용. 추가 데이터 원본 불필요, 구현 1분.

## PHASE 6: 대시보드 레이아웃 (5분)

기존 Tab3 대시보드를 그대로 사용. 추가 작업만 수행:

### 대시보드 높이 변경

기존 1600×900 → **1600×1050** (약간만 늘림, 성향 컨트롤 영역 추가분)

### 레이아웃

```
┌──────────┬──────────────────────────────────────────┐
│ 사이드바  │ [상단] 제목          | 기간 선택 버튼     │
│ 로고      │                     | 성향: ○공격 ●균형 ○안정 │
│ 신뢰성검증├──────────────────────────────────────────│
│ 2026전망  │ ■■■ 구분선 ■■■                           │
│ 투자발굴  ├──────────────────┬───────────────────────│
│           │ 섹터 랭킹        │ 산점도                 │
│           │ (추천=색상강조)   │ (추천=크게+라벨)       │
│           ├──────────────────┴───────────────────────│
│           │ 산업 리스트 (추천 순위 컬럼 추가)          │
└──────────┴──────────────────────────────────────────┘
```

**변경 사항:**
- 상단 우측에 `P_투자자성향` 매개변수 컨트롤(라디오 버튼) 추가
- 기존 차트 3개는 위치/크기 변경 없음
- 차트 내용만 추천 하이라이트가 추가됨

### 매개변수 컨트롤 배치

1. 대시보드에서 `P_투자자성향` 매개변수 우클릭 → 매개변수 컨트롤 표시
2. 라디오 버튼 형식으로 변경
3. 상단 기간 선택 버튼 옆 또는 아래에 드래그 배치
4. 제목을 "투자 성향" 또는 빈 문자열로 설정

## PHASE 7: 서식 통일 (3분)

### 추천/비추천 색상

| 구분 | 색상 |
|------|------|
| 비추천 | `#D0D0D0` (연한 회색) |
| 강력매수 (클러스터 1) | `#2E7D32` (진한 녹색) |
| 고수익·고위험 (클러스터 0) | `#E65100` (오렌지) |
| 안정형/중립 (클러스터 2) | `#1565C0` (파랑) |

- 배경: 본문 `#F5F5F5`, 사이드바 `#3C3C3C`
- 폰트: Noto Sans CJK KR
- 카드 배경: 흰색

## 핵심 연동 원리

```
기간 선택 버튼 클릭 (기존 그대로)
  → 필터 동작: Horizon 필터 전파
    → 섹터 랭킹, 산점도, 산업 리스트 모두 해당 기간만 표시

성향 라디오 버튼 변경
  → 매개변수: P_투자자성향 = "공격형"
    → C_추천여부: Is_추천_공격형 값 반영
    → C_추천순위: Rank_공격형 값 반영
    → C_마크색상구분: 공격형 추천=클러스터색, 비추천=회색
    → C_추천라벨: 공격형 추천 산업에만 순위+이름 표시
```

**두 컨트롤이 동시에 작동:**
- "스윙 + 안정형" 선택 → 스윙 기간의 안정형 추천 산업이 하이라이트
- 기존 차트의 모든 산업이 보이면서, 추천 산업만 시각적으로 강조
- 비추천 산업은 회색으로 배경에 남아 전체 시장 맥락 유지
